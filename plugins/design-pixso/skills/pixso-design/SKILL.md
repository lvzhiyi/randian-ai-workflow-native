# Pixso 设计来源

本插件自带 Pixso MCP 配置（`https://pixso.cn/mcp`，首次使用按提示登录授权）。如果你在用户或项目级已经配置过同名 Pixso MCP，保留一处即可，避免工具重复。

## 定位

- 权威设计文件由项目配置或设计索引给出：文件 key（链接 `/app/design/<key>` 中的部分）、页面 `page-id`、节点 `node-id`（链接中 `%3A` 即 `:`）。
- 同一文件里常有同名多稿（如两个“密码登录”画板）：**不按节点编号或画板顺序猜新旧**，列出候选请用户确认主稿，并在设计索引记录确认人和日期。
- 原型、流程白板（`/app/board/`）只作流程参考，不作视觉依据。

## 读取层级（每次在设计索引写明读到哪一层）

| 层级 | 工具（以当前会话实际暴露的为准） | 能声明什么 |
| --- | --- | --- |
| 顶层画板清单 | `get_top_level_frames` | 页面有哪些画板 |
| 结构与文字 | `get_node_dsl`、`query_nodes` | 层级、文字、尺寸、坐标 |
| 样式与变量 | `read_styles`、`read_variables`、`get_style_guide` | 共享色值、字体、组件样式 |
| 截图 | `take_screenshot` / `get_export_image` | 视觉外观 |
| 素材 | `get_export_image`（按节点导出） | 图标、插画原始资源 |
| 评论 | `read_comments` | 设计说明与讨论 |

- 只读到结构/文字时，**不声明视觉已核对**；没导出素材时不声明素材已确认。
- 导出的 PNG/SVG 检查尺寸、透明底、裁切；不用手工转写的 SVG 冒充原图。
- `design_to_code` 生成的代码只作参考，按项目主题、组件和分层重写，不直接粘贴。

## 设计值与项目规则

- 页面明确的设计值（颜色、字号、字重、圆角、间距、素材）优先于全局主题默认值；覆盖值集中在页面样式文件，注明节点与核对依据。
- 设计没给的状态（加载、禁用、错误、空态、深色、窄屏、大字体、键盘）按项目 UI 规范补齐，标明是项目适配而非设计原值。
- 字体文件仓库里没有时不擅自下载引入；记录用系统字体回退。

## 设计索引最小字段

设计资源编号、用途、文件链接与 key、页面名/ID、节点名/ID 及链接、版本或核对日期、主稿确认依据、关联共享 UI/子需求、读取层级、差异与恢复条件。无法确定的写“待确认”。

## 视觉核对

在相同尺寸、缩放、状态下比较设计截图与实际截图；记录节点、核对日期、代码版本、设备和未覆盖项。自动截图或 Widget 渲染不替代产品视觉验收。
