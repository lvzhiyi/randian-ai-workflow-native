# 任务级只读看板

`${CLAUDE_PLUGIN_ROOT}` 指插件根；未替换时从 `SKILL.md` 向上三级定位，执行代入绝对路径。Codex 前置 `WORKFLOW_HOST=codex`。

## 执行

用户明确调用才使用；取 `on | off | status`，未给操作默认 `status`，不得自行开启。项目根取用户指定或调用前 cwd，不把插件根当项目根；用户给任务 ID 才带 `--task`，不猜测。

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/dashboard_server.py" status --root "项目根"
```

需要时将 `status` 换成用户请求的 `on` / `off`，附实际支持的 `--task "ID"`。先核对脚本实际 `--help`。只转述命令返回的服务状态与本机 URL，不自动打开浏览器。脚本缺失、端口/权限/沙盒失败明确报告，不自动安装依赖或重配权限；需要用户本机执行时提供同一命令。

## 展示与边界

以任务为单位展示档位、主状态、阶段说明、局部流程、todo 进度、任务内失败/阻塞/待确认、有效证据与下一步；不展示全局八步或独立阻塞区。详情读取当前轮次的批准版本、基线读取、验证清单、两轴评审与轮次/尝试历史。文档勾选不替代引擎证据，Agent 评审通过不替代人工验收/交付。

Trace 整合为本入口的执行观测，不再推荐独立 `trace on`。事件关联项目/任务/会话/轮次，未归属事件只作线索，不改状态。业务阶段与活动状态分开：展示实际执行者、会话、最后活动与新鲜度；无退出/心跳证据仅为“活动未知”，不从静默猜阻塞或失联。

本技能仅开关本机服务和只读查询，不批准、不写流程状态或项目文档。服务开关不是 engine 开关，防护栏始终启用。除服务运行数据外不额外修改，文档仅按纯文本查看；不要把页面当流程控制台。Claude 已有版本绑定的原生确认流程回调，Codex 使用人工终端兜底；实际缺失数据明确标注，不宣称双宿主端到端实测、可信签署、抗程序代答或全写入路径覆盖。
