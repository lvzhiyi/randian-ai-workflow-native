# 中断与恢复交接

下文的 `${CLAUDE_PLUGIN_ROOT}` 指当前技能所在的插件根目录。如果它没有被替换成绝对路径（如在 Codex 中），从已加载的 `SKILL.md` 路径向上三级定位，执行命令时直接代入绝对路径。

中断指工作没结束就暂停、换会话、上下文将耗尽、换人/换 Agent 或异常退出，不要求出错。受阻问题仍按 `verify` 分类，用同一份任务记录，不维护两套状态。

## 记录位置（以项目配置为准）

- 有规格变更（如 OpenSpec change）：`<变更目录>/handoff.md` 保存当前快照；tasks 仍是唯一完成清单，handoff 只链接任务编号。
- 无变更的跨会话任务：项目配置的交接目录，默认 `docs/development/handoffs/<task-id>.md`，task-id 简短唯一；目录不存在时在第一次交接时创建。不为普通 Bug 强行建提案。
- 当次完成的小任务不建交接文件；**未完成且准备换会话时必须写入仓库**，不能只依赖聊天摘要。
- 续做时按用户给的任务/变更查找记录；多个候选对不上先确认，不按修改时间猜。

## 何时保存

1. 开始明确需要跨会话的任务时，建最小记录并标“进行中”。
2. 完成有意义的小步骤、关键决定改变、拿到重要验证结果时更新，特别是长命令启动前。
3. 暂停、交接或会话结束前更新为“已暂停 / 受阻 / 实施完成，待验证”，写第一条可执行的下一步，并告诉用户记录路径。
4. 异常退出无法保证写入；恢复者以 Git 和实际文件重建缺口，不把快照当自动备份。

模板：`${CLAUDE_PLUGIN_ROOT}/templates/handoff.md`；模板未覆盖的任务级字段原位补齐：任务 ID、协议版本、当前轮次、阶段/尝试 ID、主执行者/会话、授权摘要与来源链接、适用基线及读取版本、有效/失效证据、失败/中断原因、未完成 todo、恢复条件和第一步。区分 Agent 评审通过与人工验收/交付，不建第二份状态权威。不保存 token、测试账号密码或完整敏感日志；机器上的临时文件不算跨机器交付物。

原生清单遵守 `workflow` 的“安全同步与聊天降级”：按真实 schema 核实数量、必填参数和已有列表可见性；单项、空清单、不能安全清理旧项或工具拒绝时使用简短聊天清单，不凑假 todo、不覆盖未知列表、不声称已原生同步。CLI 只是投影，由 Agent 显式调用宿主工具，不提供自动 UI bridge。

## 恢复步骤（所有 Agent 接手的唯一步骤来源）

不依赖上一位的聊天记忆、工具会话或本机临时文件；只读授权范围相关材料。

1. 查询实际引擎 `status` / `snapshot` / `history`（入口见 `workflow`），核对任务、当前轮次/尝试及证据有效性。读根目录规范、交接记录、相关规格/设计和任务清单，确认目标与已批准范围。新 Agent 成功完整重读适用必读基线，记录自己的回执，但不重批仍有效的方案。产品任务先从项目首页/总览定位模块卡，再由卡定位需求章节和设计索引。前任的建议或“已读取”不等于批准。
2. 查看当前目录、分支、HEAD、`git status --short`、相关 diff 和必要日志，与快照比对；未提交和未跟踪文件单独确认。对照源码区分目标、已实现、已验证。
3. 检查期间其他人的改动，归属不明时不覆盖；**不为恢复快照自动 reset、clean、stash 或检出覆盖文件**。
4. 检查快照里记录的运行中命令和服务是否真的存在、结果是否已生成；会话 ID 和进程 ID 可能失效，不盲目重复有副作用的操作。
5. 核实 SDK、依赖、接口和设备，重跑最小基线或原失败用例；代码变了的旧“通过”只作参考。缺记录时先调查现状，形成新快照。
6. 使用实际 CLI `resume` 复用有效轮次，只登记活动、不跳门禁。原范围失败重试追加阶段尝试，不重复审批；人工退回开启新轮次并重新授权，取消不可自动恢复。孤立 running 仅在确认所有者已死亡后使用实际 `recover`，中断不能当成功。说明本轮可推进范围、所缺条件和最小验证，从第一项未完成继续；验收、范围或实质方案变了回到确认。静默或会话信息缺失仅为活动未知，不推测阻塞。
7. 恢复后调用只读 `progress --task`，按 `workflow` 核实原生工具并从当前轮次重建宿主清单；不用交接快照或宿主旧列表覆盖引擎。refine-steps / repair 后重新读取，保留同轮稳定 ID，排除旧轮次；只有 implementing 的首未完成项可标运行中，失败、失效、评审失败显示暂停/待修复。结束或中断前同步真实阶段，并在权威记录里保存决定依据、实际结果、未覆盖项和下一步；无原生工具时给简短聊天清单。

## 收尾

任务真正结束后把快照标为“已结束”，链接实际验证和 PR/交付记录，保留未解决事项。规格变更的交接随变更一起归档。写交接文件不自动授权提交、推送或归档。
