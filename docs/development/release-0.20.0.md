# workflow-core 0.20.0 — 批量基线读取与任务卡回写

- Agent 可批量读取并登记必读基线。遇到宿主输出上限时可分批读取。
- 已绑定模块卡的任务在双轴评审通过后，自动将协作状态更新为「评审通过，待人工验收」。人工验收和交付由实际确认记录。回写中断可按原请求重试。
- 人工定档及完整档方案批准可在 Agent 窗口处理。按宿主使用原生选项或约定的聊天回复，交互终端命令继续可用。
- 完整档批准后写入 `proposal.md` 与 `design.md`，实施进度由引擎维护。OpenSpec 退出默认流程，已有规格文件可继续作为项目文档使用。
- 看板聚焦任务进度、验证与评审证据，旧 Trace 入口已移除。

升级后新建会话以加载更新后的技能与 hooks。宿主门禁覆盖受支持的工具路径，真实客户端端到端验收仍待补齐。回写配置见[引擎文档](workflow-engine.md#评审通过后的任务卡回写)。
