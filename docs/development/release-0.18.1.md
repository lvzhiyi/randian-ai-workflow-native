# workflow-core 0.18.1 — 修复规划与看板自举

## 修复

- PRD 拆解和初始化增加会话级精确规划授权，不再为了写模块卡、总览与 README 入口要求先创建实施任务。
- 规划授权绑定项目、会话、操作、目标清单和有效期，支持关闭及审计；仅授权明确文档编辑，不放行混入源码的补丁、任意 Shell 写入或 MCP 混写。
- 固定 Dashboard 入口的 on/off/status 无需绑定任务，支持三宿主前缀及合法参数顺序，仍拒绝额外参数和 Shell 拼接。
- 初始化固定探测、忽略规则检查和配置校验无需实施任务，配置生成后仍可继续创建已授权骨架。
- 规划目标排除不可配置覆盖的插件源码和模板边界；兼容 macOS 系统祖先路径别名，继续拒绝项目内符号链接。
- 无任务提示区分规划、服务管理和产品实施，不再一概要求先 start。
- 新配置模板仅生成 baseline 清单，code_rules_doc 作为旧配置兼容入口合并去重。

## 升级与验证

请更新插件后新建会话，以便加载新增 workflow_planning_cli.py 和技能登记步骤；无需删除原项目配置、创建虚假实施任务或禁用门禁。已有 code_rules_doc 可以保留，旧项目不会因此重复读取同一基线。

发布前执行 python3 scripts/check.py（294 项测试）和 git diff --check。证据包括真实 CLI 集成及模拟三宿主门禁；真实宿主端到端回调与人工验收仍需复测。人工确认继续沿用现有宿主能力边界，插件不是安全沙箱。
