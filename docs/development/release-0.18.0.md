# workflow-core 0.18.0 — Cursor 原生适配

## 变化

- 新增 Cursor 原生插件与多插件仓库清单，独立扁平 hooks 配置，不依赖 Claude hooks 自动转译。
- 新增 Cursor 事件适配器，归一化 conversation_id、工具输入输出和权限结果，复用既有任务引擎与门禁。
- 支持最近项目边界、多根与实际 Shell 目录隔离；未接入项目不拦截、不采集，已接入项目故障不降级。
- Cursor 写入与子代理启动使用合法权限响应；Git 调查输入更新保留原字段。
- Cursor Trace 使用数值时间戳和独立本机目录，与看板同源，沿用有界归属与输出规则。
- 补充安装说明与 Cursor 回归测试，保留 Claude Code / Codex 原有入口。

## 验证和边界

发布前执行 python3 scripts/check.py 与 git diff --check。适配已有官方协议形状模拟、真实引擎和跨项目隔离测试；真实 Cursor 安装和会话端到端验收尚未完成。

Cursor IDE 未公开已验证的稳定问答/方案批准回执，档位确认和完整档方案批准使用人工交互终端兜底；完整基线仍通过 CLI 输出正文并登记，不把普通问答或未知读取结果视为授权证据。

本期仅 workflow-core 提供 Cursor 清单，其他技术栈/设计/接口插件不在适配承诺内。插件门禁不是安全沙箱，不提供可信签署、抗程序代答、同账号防篡改或全部工具路径覆盖。
