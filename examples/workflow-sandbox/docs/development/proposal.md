## 范围与接口

仅实现 P01～P05，不接入引擎、不扩大为真实个人任务工具。
命令：`python3 src/task_cli.py --file PATH <子命令>`；必须显式指定文件。
子命令：`add TITLE`、`list --status all|pending|completed`、`complete ID`、`undo ID`。
新增输出包含 ID 的 JSON 对象，列表输出数组，状态操作输出对象；错误只写 stderr，不输出数据文件内容。参数解析错误退出 1，帮助退出 0。

## 模块与存储

- `src/task_domain.py`：纯业务校验、编号、筛选与状态转换，无文件 IO。
- `src/task_store.py`：严格结构校验、损坏保护及原子保存。
- `src/task_cli.py`：参数解析、领域与存储编排及稳定错误分类。
- `tests/`：领域、存储、真实子进程 CLI 和检查入口测试，数据均临时创建。
- `scripts/check.py`：文档、格式、静态与测试统一入口，拒绝零测试，缺工具返回受阻。

快照严格包含 version=1、next_id、tasks；每项仅含 id、title、status。整数拒绝 bool；ID 唯一，next_id 大于所有已有 ID。标题和状态读取时校验。只读不建文件或目录；父目录必须已存在。
只支持单写进程，不提供锁与自动合并。保存采用同目录唯一临时文件，权限 0600，flush/fsync 后 os.replace，异常清理。原子可见性不等于断电耐久性；拒绝符号链接。
