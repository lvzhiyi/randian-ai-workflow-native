# 本地待办清单 PRD

版本：1.0；日期：2026-11-14；来源：本次工作流演练模拟需求，并非真实客户需求。

## 目标与范围

单用户在终端管理本地待办，所有数据保存在用户显式选择的 JSON 文件中。首期不含登录、云同步、删除、优先级、截止日期或图形界面。只使用合成数据。

## P01 新增待办

标题去除首尾空白后应为 1～80 个 Unicode 码点；空标题或超过 80 字拒绝。内部空白保留。不因非法输入分配 ID 或改动已有数据。
新增项初始状态为 pending，ID 为正整数且在同一数据文件生命周期中不复用；成功输出新 ID。
同名标题允许重复创建，每条记录用唯一 ID 区分；确认依据见 Q01。

## P02 查询与筛选

列表按 ID 升序展示 ID、标题和状态。支持 all、pending、completed 筛选，默认 all；空结果输出空列表。非法筛选值拒绝且不改数据。

## P03 状态转换

完成：pending → completed；撤销：completed → pending。重复完成或重复撤销为幂等成功，不产生新条目。不存在的 ID 或非正整数 ID 拒绝且不修改数据。

## P04 持久化与恢复

进程退出后重新运行仍可读取已有数据。不存在的数据文件视为空清单，仅成功写操作才创建文件。
损坏 JSON、重复 ID、不支持的状态或结构不合法必须报错，不自动覆盖或清空原文件；修复文件后允许重新读取。写入应原子替换，失败不得损坏旧文件。本期不支持多个写进程并发，必须在使用说明中声明。

## P05 输出与退出码

成功返回 0，业务输入错误返回 1，文件读写或数据损坏返回 2；错误写 stderr。列表结果使用 JSON，便于测试，不向错误输出泄露文件内容。

## Q01 待确认需求

原问题：同名标题（去除首尾空白后、大小写敏感）是否允许重复？

决定：允许重复，每条待办以唯一 ID 区分。
确认人：本次用户；确认日期：2026-11-14（UTC+8）；依据：此前会话 Q01 结构化问答选择“允许重复”。本次为恢复历史决定，并非新增审批。

## 验收范围

覆盖 P01～P05 的成功、空状态、边界、业务拒绝、存储损坏及恢复；数据都在临时目录创建。文档和测试通过不等于真实宿主钩子已验收。
